# ProyectFL
Sistema de gestión de inventario y pedidos para florería con flujo de trabajo Git

# Editar el README
cat > README.md << 'EOF'
# 🌹 Florería Rosales - Sistema de Gestión

**Estudiante:** [Tu Nombre Completo]  
**Fecha:** Octubre 2025

## Descripción del Proyecto
Sistema web para gestión de inventario de flores y pedidos de la Florería Rosales. Este proyecto demuestra el flujo de trabajo profesional con Git usando ramas main y feature.

## Características
- Catálogo de flores disponibles
- Gestión de inventario en tiempo real
- Sistema de pedidos de clientes
- Cálculo automático de precios
- Filtrado por tipo de flor y ocasión

## Productos
- Rosas (rojas, blancas, amarillas, rosadas)
- Tulipanes
- Girasoles
- Orquídeas
- Lirios
- Arreglos especiales para ocasiones

## Tecnologías
- HTML5, CSS3, JavaScript
- Git para control de versiones
- Diseño responsive

## Flujo de trabajo Git
Este proyecto implementa un flujo de trabajo con:
- **main**: rama principal estable con versión de producción
- **feature branches**: ramas para desarrollo de nuevas características
- **Pull Requests**: revisión de código antes de integrar cambios

## Estado del Proyecto
🌸 En desarrollo activo
EOF
